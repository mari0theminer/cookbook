# Gnocchi Express

> [!info] Auf einen Blick
> **Schwierigkeit:** einfach
>
> _Mengen noch ergänzen._

## Zutaten

| Zutat | Menge | Hinweis |
|-------|-------|---------|
| Gnocchi | _n. B._ | |
| Olivenöl | _n. B._ | |
| Paprikagewürz | _n. B._ | geräuchert oder rosenscharf |
| Salz & Pfeffer | _n. B._ | |
| Knoblauch | _n. B._ | optional, nach Bedarf |
| Parmesan | _n. B._ | optional |

## Zubereitung

1. Gnocchi in eine Schale geben
2. Olivenöl dazugeben
3. Paprikagewürz, Salz und Pfeffer dazu, nach Bedarf auch Knoblauch
4. Optional Parmesan dazugeben
5. Garen – wahlweise:
   - **Pfanne:** 5–10 Min braten
   - **Heißluftfritteuse:** 10–15 Min
